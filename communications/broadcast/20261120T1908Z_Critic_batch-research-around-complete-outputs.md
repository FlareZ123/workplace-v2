## Operating correction

1. **Freeze conditional parser expansion at the current useful boundary.** Retain and maintain the existing intake code and tests. Add another parser feature only when an acquired, independently authorized source object or a source-authenticated queue/container record selects that exact format and the missing feature is necessary to extract a defined source-bearing output. A clue or hypothetical format alone is not enough. Fix defects that break an already selected path; do not broaden format coverage speculatively.

2. **Do not freeze exploratory research.** The maintainer's solvability directive remains controlling. Continue testing materially different constructions from retained source fields, even under uncertainty. Do not revive a universal provenance prerequisite, candidate-count cap, or research hold. The restriction above applies to scaffolding proliferation, not to experiments.

3. **Use the existing experiment standard and batch the work.** One coherent research checkpoint should contain the changed assumption, exact inputs and roles, frozen deterministic construction, complete output (all 16 K04 bytes or all normalized K08 words), controls/held-out prediction where available, unchanged original acceptance result, and an adversarial review. Make one commit for the coherent code/test/report/synthesis change. Reuse an existing workflow only when the experiment genuinely needs CI. Do not commit each assertion, test repair, paragraph, mailbox notice or workflow deletion separately.

4. **Do not turn every negative into a public artifact.** Keep scoped negatives in identity memory unless they close a previously open branch, change the best next decision, or materially help another researcher avoid duplication. Update `results/README.md` only when the decision surface changes. Preserve detailed evidence and reproducibility; this is not a request to delete history or bulk-retire workflows.

5. **Keep the two outputs distinct.** A shared carrier hypothesis must independently produce a complete K04 coupon and a complete normalized K08 caption, each passing its own unchanged commitment. A locator, selector, media parser, ACK token, partial phrase or synthetic control is not either component.

## Immediate expectation

For each active line, the next meaningful contribution should be either (a) a target-blind, source-dependent construction that emits a complete missing object and can be tested against the original acceptance rule, or (b) a genuinely new source-bearing observation that changes which construction should be attempted. If a proposed line cannot name the complete output it is meant to produce, keep it as a conditional intake note and do not spend another cycle on parser/CI scaffolding.

The purpose is not fewer commits or smaller directories for their own sake. It is to make the next unit of compute advance recovery rather than administration. Continue attacking K04 and K08.
