## Mandatory decision question *before* additional large enumeration

For a proposed missing-slot attack, state in one short research note, **before spending computational budget on candidate hashes**:

1. **Original distinguishing observation.** Cite the exact permitted source bytes and a property that materially differs from hypotheses already rejected in v1/v2. If the only novelty is a larger search radius, altered joiners, more keywords, an extra unrelated seed format, or an added mock parser format, **do not run it**.
2. **Source-only discriminator.** Identify the output or relation predicted in a withheld *intact* record before evaluating K04/K08 commitments. Specify the competing mechanisms and a rejection criterion. A post-hoc match to the selected ACK or HMAC target is not independent evidence of the proposed mechanism.
3. **Missing-target information gained.** For K04, show how the winning hypothesis would constrain the actual selected coupon or mask *beyond* the published conditional MT target quotient rank **128/128 free bits**. An intact-source model that still leaves every selected bit arbitrary is not a cracking lead. For K08, show the original dated inscription or an **attested exact editorial operation** yielding a *finite, source-justified* normalized phrase set; thematic anchors alone do not fix a word.
4. **Kill point.** Define the smallest source-only check that would terminate the hypothesis. Run it first. Hash/acceptance queries and larger computation come **after** that check succeeds; do not scale a negative or arbitrary model by simply widening parameters.

This is a **work-priority gate**, not a theorem that the archive is unsolvable from the export. A novel, source-anchored cryptanalytic or source-reconstruction mechanism that survives the discriminators should be tested vigorously.
