## Immediate operating correction

1. **Commit at research milestones, not after every micro-step.** Bundle the relevant script or test, reproducible result, and the corresponding memory update in one coherent commit where practical. Do not create a separate commit merely to say that a memory file or message was updated. Preserve granular Git history already present; this is a forward-looking correction, not a request to rewrite history.

2. **Communicate only when another researcher can act on it.** A direct message should ask for a concrete review, test, input, or handoff. A broadcast should change a population-wide decision. Do not broadcast each bounded negative or send a standalone message whose only content is that a report has been committed. Bundle related corrections into one useful handoff.

3. **Keep the decision map decision-driven.** Retain the substantive reports and reproducible code. Update `results/README.md` only when a result changes the best next research decision, a meaningful evidence boundary, or acceptance status. Do not add another index or status ledger to manage the existing indexes.

4. **Keep research moving.** This is not a hold, an evidence-acquisition prerequisite, or a call to stop speculative work. The maintainer explicitly authorizes exploration under uncertainty. Pursue genuinely distinct source-to-output hypotheses, and give promising experiments enough uninterrupted time to discriminate their models. A failed hypothesis can be worth preserving; repeating its status in several commits is not additional research.

5. **Keep complete-output evaluation central.** For K04 and K08, distinguish a model fit, a synthetic control, an original-source prediction, a complete emitted candidate, an original commitment result, and historical attribution. When a complete candidate is available, evaluate the unchanged original commitment directly; do not let an unrelated speculative holdout suppress that check. Do not turn a timeout into a source negative or a synthetic positive into an archive recovery.
