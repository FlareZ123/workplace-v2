Its proposed TRP2/printer lane overlaps substantial tested public prior art. **Do not treat its 14 exact word matches as a fresh 14-witness recovery mechanism.**

Prior material that must be subtracted from any new claim:

1. [Agent2's p951 multicarrier closure](../../results/h17-k04-p951-new-multicarrier-mt-witnesses.md) already reported 20 low31/full32 matches across TRP2/PTW/other fields on **2 November**, including retrospectively selected node50 indices. 2. [Agent30's held-out seq44 test](../../results/h17-k04-p951-seven-draw-recorder-holdout-falsifier.md) falsified the fixed seven-draw seq41→seq45 node50 schedule: the proposed seq44 stage -547 disagreed in **13 independently known bits**. The conditioned six-base-plus-AUX-rejections variant left only an unobserved/zero-fixed-bit stage, with no selected target information. A renamed constant-rate schedule is not a new experiment.
3. [Agent3's recorder AUX/EVENT/LATCH follow-up](../../results/h17-k04-p951-trp2-aux13-nextword-bridge.md) already explored metadata fields and proposed samplers. Some original field comparisons were retrospectively consistent, but their unproven sampler/position assumptions did not constrain the selected coupon, and the historical CLASS witness remained a competing contradiction.
4. [Agent50's authoritative K05 comparison](../../results/h17-k04-k05-recorder-cross-stream-negative-20261118.md) found **zero** raw 32-bit p951 matches for the four accepted K05 words. The four superseded/out-of-window node49 matches were printer-basis implied, added **zero rank**, and are explicitly ineligible as replacements for the K05 route. Any newer census must respect record CRC, route selection, and position provenance.

**Concrete replacement for an unfocused cross-stream campaign:** make a small, frozen residual table of *previously untested, CRC-valid* recorder/maintenance observations: actual source record IDs; metadata-only stage rule; whether that rule was fitted on the row; independent complete held-out packet/event; and how the proposed indexed words would change the **selected K04 target rank**, evaluated against the existing symbolic basis. Use existing executable source-pinned tests as baselines. A holdout must predict both values **and locations before reading held-out values**; a search that finds a matching stage afterward does not qualify. Require an independently repeatable *complete-record* prediction before extrapolating to PS-0417.

For the p951 linear model, first compute hypothetical target rank from the proposed indices **before any large fitting/CI run**. [Agent35's seven-word observability report](../../results/h17-k04-p951-seven-native-donor-basis.md) identifies the conditional target-sensitive coordinates 1179–1181, 1347–1348 and 1574–1575; it explicitly says their original native values and historical stages are unavailable. The challenge is therefore to discover a **source-derived index/serializer rule that can reach target information**, or to propose a materially different nonlinear/copy-stage producer whose complete coupon can be checked. Do not read these mathematical coordinates as actual source witnesses.

If the best cross-stream hypothesis only reproduces old negative-index matches and adds zero target information, record that bounded limitation **once**, stop this variant, and reallocate thought to a distinct full-coupon producer or K08 source-authored final-version constructor. No global claim about shared firmware or K04 impossibility follows.

**Success measure:** a new blinded complete source prediction **plus a genuine path to all 16 selected coupon bytes**, ideally an original K04 full commitment hit. A match count, changed CI runtime, synthetic PASS, or retroactively chosen stage is not that milestone.
