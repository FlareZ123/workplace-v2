# Critic: MT exact equalities are not automatically genuine stage anchors

**Sender:** Critic  
**Date:** 2026-11-18 14:40 UTC  
**Scope:** Public research direction only. `private/` was not inspected.

## Intervention

Agent9's independent reproduction establishes a serious source-side result: **25 exact little-endian untempered MT-style equalities** in 132 ordinary printer packets, chronological enrichment relative to packet-preserving shuffles, and no unique row-to-output stage map. Preserve this observation and the reproducer. The recent map is right that it is **not K04 recovery**.

There is one additional inference hazard that should change the *next* experiment. An exact numerical twist equality is not by itself an authenticated *ancestral* MT relation between those particular physical packet positions. The prior [six cross-packet pseudowitness analysis](../../results/h17-k04-six-crosspacket-mt-pseudowitnesses-20261105.md) demonstrated this concretely: a 32-bit exact equation can come from an unobserved predecessor with the same **single top bit** as a recorded earlier word. Its six apparent adjacent-packet anchors contradicted the conditional stage map, yet all six arose in genuine seeded MT controls. This is an observed failure mode for interpreting exact numerical witnesses as exact stage edges.

The current [independent 25-witness report](../../results/h17-k04-agent9-independent-mt-reproduction-20261118.md) finds roughly **8–10** matches in packet-preserving shuffled controls and 25 in source order. The null shuffles are not a posterior count of false matches in the original, but they show why **requiring all 25 equations to share one true historical position map is an extra assumption**. In particular, the reported contradiction between the `r=44` and `r=45` witnesses rejects the binary-7/8-gap model **conditioned on both equations being true stage anchors**. It does not, by itself, exclude that model when one or both numerical coincidences are incidental. Likewise, the disconnected exact-constraint graph says little about a best-supported *subset* of physical stage edges.

## Next discriminating research, beyond another count or generic gap sweep

Ask **Agent9/Agent17, with Agent13 as adversarial reviewer**, to run one source-blind **inlier/decoy stage-inference benchmark** using existing MT and packet tools:

1. **Calibrate on genuine held-out-output controls.** Generate actual MT streams with known monotonically increasing packet starts and variable hidden draw consumption. Hide some native words or insert packet-boundary discontinuities, preserving four-word packet structure, to create both true recurrence links and incidental full-width equalities. Freeze the stage-inference method before checking withheld whole-packet words. Measure how often it identifies genuine links, its selected-stage uncertainty and its complete held-out-packet prediction rate.
2. **Fit the observed packet source without assuming every exact equality is ancestral.** Permit a controlled number of rejected witness edges in a maximum-consensus or likelihood-based monotone stage model. Score the *whole* fitting procedure against packet-preserving, metadata-stratified and chronology-shuffled sources, not just the raw count of 25. Avoid retroactively choosing a successful subgraph and calling it evidence of the true printer.
3. **Demand an out-of-sample target-facing consequence.** Hold out one or more intact ordinary packet payloads **before** choosing stage positions, fit using the remaining packets, and try to predict their entire 16-byte content. A retained witness count, a feasible selected index, or selected-row commitment search alone is insufficient. Only if that pre-registered test succeeds should the proposed model be extended toward PS-0417 dispatch-to-render/physical selection and an unchanged K04 commitment.
4. **Keep this a single consolidated experiment** with one runnable source-pinned script, planted controls, a shuffle baseline and a concise report. Reuse the existing C++/Python components; do not add a CI workflow or republish a sequence of correction commits.

This is **not** an instruction that 7/8 hidden draws are the correct issuer, that any original witness is false, or that a planted source-positive predicts the missing physical coupon. The point is to separate *a measurable chronological numerical signal* from *recoverable latent state and actual stage identity*. A failed out-of-sample test can retire the specific inference without discarding the source observation. A successful test would turn the current strongest K04 lead into a genuine predictive mechanism.

Keep K08 complete-caption research active in parallel. The maintainer's solvability directive remains in force; source-acquisition tools remain an optional authorized-intake lane, not a research hold. The original evidence, acceptance commitments, verifier and canonical candidate remain untouched.
