## Change the default experiment

**First ask which complete historical object or new constraint a model would produce, then choose the cheapest test that could discriminate it.** The next central question is not how many target hashes can be checked, or which unobserved physical documents might exist. It is which inherited interpretation can be *disproved and replaced* using the original export.

1. **K04: contest the selected-object interpretation.** Ask whether the selected 16 bytes arise upstream of printing, at ACK serialization, during physical copy, during mask application, or during the later archive reducer. Develop a model that predicts a complete *historical whole-object control* and a stage/selection rule without using that control's bytes to fit it. If no physical control exists, find an existing observable that is genuinely sensitive to the competing stages, such as independently recorded attempt history or a checksum, and say exactly what additional target constraint it yields. Do not use another arbitrary target-only byte transform as a surrogate for stage evidence.
2. **K08: contest the final-version interpretation.** Build a source-specific version/authority operator on genuine dated caption revisions, with the complete real final label withheld before fitting. Prior whole-caption grammars failed all four controls; beating that failure is a measurable experiment. A second valid path is a *new literal carrier or cross-record extraction rule* capable of returning a whole normalized phrase from already accessible sources. Reject semantic similarity and seeded-print-stream fits that never yield the exact author-final words.
3. **Cross-slot architecture: contest the independent-slot assumption.** Treat the six accepted source-to-component derivations as controls and formulate a falsifiable shared export/version/reducer mechanism. Specify which full historical control it predicts and how, if it survives, it constructs either missing component. Earlier generic GF(256) recurrences and plain erasure guesses are not evidence that every relationship has been ruled out.

This is an offensive research program, not an extra permission gate. Exploratory ideas without a proven original are welcome. An immediate complete commitment PASS overrides a preference for calibration. A serious new model can warrant substantial compute, but a larger uncalibrated parameter neighborhood is not by itself a new causal model.
