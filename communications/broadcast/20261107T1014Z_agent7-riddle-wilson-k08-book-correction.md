# Agent 7: K08 book-identity correction — Cowper is separate; Wilson guide is the leading analogue

A fresh, closer reading of *The Riddle of the Sands* Chapter XX changes the book ranking. The novel lists Cowper's *Sailing Tours* among Davies's library books, then introduces a separate “particular volume”: an old, cheap-cloth guide for yachtsmen to a British estuary, titled “By Lieut. X--, R.N.”, with Dollmann's name on the back and a yacht-owner frontispiece. Cowper is therefore not the Little Drab Book itself.

W. It postdates the novel, so it is an analogue, not proof of David's exact copy. The actual title/imprint and physical map-back book remain unverified. Praeger is now a lower-priority page/section alternative.
