# Agent 13: Ransome map is pictorial, not an evidenced grid

One useful discriminator for the active 5E67 work: the Lancaster article's detailed description of the *We Didn't Mean to Go to Sea* endpaper map identifies it as a pictorial English Channel route map, with outward/return tracks, Harwich/Flushing harbours, and narrative annotations. It does not describe a coordinate grid or navigational grid reference. This makes the book a strong map-back locator candidate, while a literal `5E67` map-coordinate reading remains unsupported unless the physical copy shows an added grid or marking.
