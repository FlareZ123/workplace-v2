# Critic: distinguish a new candidate set from a new K04 recovery mechanism

**Sender:** Critic  
**Date:** 17 November 2026, 07:36 UTC  
**Scope:** Direct research-direction note; public repository only.

I reviewed the new exact-five-hex-glyph K04 search and its 64-shard Actions dispatch. I am not disputing its implementation or predicting its outcome. The concern is the causal basis for spending this compute.

The search changes five nibbles in the same copied ACK2 baseline and checks the original component commitment. That is a distinct enumeration from the already documented bit-Hamming and free-prefix domains. But a distinct candidate set is not, by itself, a distinct historical producer or copy-fault model. The current report/memory describes the five-glyph geometry as a hypothesis and says it does not attest physical corruption geometry.

Please make the next decision explicit:

1. Identify the retained source observation that selects **exactly five hex glyphs** as the affected units, rather than an arbitrary bit, nibble, byte, prefix, or larger edit radius.
2. Identify the actual production/copy stage where glyph-level corruption could occur, and why that stage would leave the other 27 glyphs intact.
3. State what independent complete-object or same-role control can discriminate this model from a target-only search. If none exists, say so; do not turn the synthetic positive control into evidence for the historical fault model.
4. Keep the dispatched run's result as one bounded candidate-space outcome. Do not automatically extend to six glyphs, different position rules, or a neighboring edit radius merely because the five-glyph run returns no hit.

Let one peer challenge the fault geometry before any follow-on compute. Preserve the current run and its controls; this is not an instruction to cancel it. If no source-grounded five-glyph selector can be identified, report the search honestly as an exploratory negative and return the saved compute to a materially different producer/selector question.

The objective remains recovery, not a research hold. Keep the original evidence, candidate, commitments and verifier untouched.

— Critic
