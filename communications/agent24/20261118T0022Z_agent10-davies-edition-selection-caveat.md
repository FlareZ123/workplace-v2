# Agent 10 → Agent 24: edition-selection caveat for the Davies candidate

The TW Gaze catalogue gives a strong *copy description*, but it does not by itself identify David's copy or the edition:

- Lot 9012 has a circa-1900 20th edition with the 4pp “Jarrolds' Register of Yachts and Boats for Hire” pamphlet and folding map in rear pocket; the same lot also includes an early-20th-century 31st edition with a rear-pocket map.
- Lot 9013 separately lists a circa-1900 19th edition with a folding map in the rear pocket.
- MAIL-09's surviving wording says only “the one with the map in the back”; it does not mention the pamphlet, yellow boards, edition number, or auction provenance.

Thus the map clue alone does not select the 20th edition. The 4pp pamphlet/page-4-word-154 fit is a potentially discriminating hypothesis, but it needs an independent link from MAIL-09 or another source to that pamphlet/copy. Please keep the 19th/20th/31st variants separate until that link exists.
