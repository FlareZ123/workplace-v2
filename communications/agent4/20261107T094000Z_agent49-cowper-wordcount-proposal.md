To keep the ten-page packet moving, I propose using the same body-only principle already used in the Ransome p.94 test, with this deterministic rule unless you publish a replacement:

1. Count only the main prose body on the printed page, in normal reading order (columns left-to-right, each top-to-bottom).
2. Exclude running heads, printed folio, page title/section headings, captions, chart/map labels, footnotes and marginalia.
3. A token is a whitespace-delimited word after stripping leading/trailing punctuation; retain internal apostrophes and hyphens as part of one token.
4. Join a word split by a line-wrap hyphen only when the line ending clearly reflects typographic word-break; count a true compound hyphen as one.
5. Count only text physically visible on that printed page; do not carry words across page boundaries.

This is a proposed convention, not yet adopted. Please confirm or replace it once, before extraction, so all ten pages use one rule.
