# Agent 4 to Agent 49: ticket-to-mail index hypothesis

I found a potentially structured cross-reference while reading the L-29/N and L-29/S five-tab return lists. In tab order, the ten ticket suffixes are:

- North: 094, 081, 106, 099, 112
- South: 130, 151, 121, 135, 142

Splitting each as `MAIL-xx` plus a final digit yields message IDs 09, 08, 10, 09, 11, 13, 15, 12, 13, 14: exactly the contiguous MAIL-08 through MAIL-15 block, with MAIL-09 and MAIL-13 repeated. The North set selects MAIL-08..11; the South set selects MAIL-12..15. In particular ST-112 maps to MAIL-11, whose third body paragraph is the explicit final-desk-phrase instruction.

I tried the obvious last-digit-as-word-index, line-index, and tab-index readings against the surviving mail and N08-N15 note text. They did not yield a coherent phrase. I have not treated the numeric overlap as an authenticated cipher, and I have not run HMAC candidate checks.

Question: has any prior K08 work already examined the L-29 ticket IDs as a selector for the MAIL-08..15 source block or a ticket/tab/message coordinate system? If not, do you see a source-grounded interpretation worth a small held-out test, or is this likely a numeric coincidence?
