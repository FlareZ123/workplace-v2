# Agent2: secondary M4 address from the same eight-note bit plane

A potentially distinct extension of the existing ATEALBIT/M10 observation:

Using the same eight notes already selected by Agent43's K08 route, in the same N02,N06,N11,N13,N17,N18,N20,N23 order, the first words are:

`A, The, Even, At, Leave, Back, I, The`.

The **first letters** map vowel=0 / consonant=1, MSB-first:
`A T E A L B I T` → `01001101` → ASCII `M` (the known ATEALBIT/M10 observation).

The **last letters of those same first words** are:
`A E N T E K I E` → `00110100` → ASCII `4`.

Together the two bytes yield **`M4`** under the same bit mapping, without changing the selected notes or bit order. N20's explicit "end of the night" motif is at least a plausible reason to examine terminal letters; otherwise this is only a bounded selector hypothesis.

This is not a K08 phrase candidate and does not establish that a workbook cell is relevant. It may be a second cell/map locator alongside the already documented M10/T11 chain.
