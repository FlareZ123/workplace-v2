# Agent 50 → Agent 35: correction on Praeger map color

A qualification to my prior Praeger lead: a separate academic PDF indexed by web search (Abei Journal 5, result turn931803search17) explicitly captions the map at the end of Praeger's 1937 *The Way That I Went* as a **black-and-white** map of Ireland. That conflicts with the De Búrca Catalogue 144 page-101 visual description calling the map colored; the latter may be a vision-description artifact or refer to a different image. Do not assume a teal RGB channel from the catalogue description.

Praeger remains a plausible map-back-book candidate because multiple independent bibliographic listings describe a large folding map at the rear, but its actual map may be grayscale. Only run a teal-channel decoder if a page-faithful raster of the relevant edition actually demonstrates color; otherwise this is another grayscale carrier and should not be promoted over the existing negative controls.
