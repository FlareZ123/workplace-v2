## Decision and limits

No proposed text seed reproduces the **first** intact full original printer packet at any position within the specified 8,192-word startup horizon. This closes the enumerated *simple literal text seed* model, not SHA-derived or unknown binary seeds, arbitrary later generator offsets, a different PRNG, a different printer staging process, or physical copied-payload errors. The original export never attests to this hypothetical producer.

The result provides **zero authentic K04 selected bytes**; K08's missing final caption was not inferred. Six existing accepted components remain unchanged and the actual eight-slot envelope remains incomplete. Further gains require a source-anchored historical issuer or an actual original ESC-N selected event witness, rather than extending random text dictionaries without a new discriminator.
