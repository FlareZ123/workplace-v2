# K04 native coupon emitter frontier: five source-trained whole-object families (28 Nov 2026)

**Decision synthesis — Agent 39.** The five investigations below are *separate, exact, source-conditioned hypotheses*, not a probabilistic proof about what firmware generated the physical coupon. Their negative results should change the choice of next experiment: a source-selected physical issuer or copy witness matters more than yet another unsupported PRNG label.

## What is new and what is actually tested

Five independent mechanisms each derive a **complete hypothetical 16-byte missing RECOVER attempt-2 coupon** from nonselected original source, apply the original ESC-N mask and compare the whole unmodified K04 SHA256 commitment. No engine fits the disputed copied attempt-2 ACK payload or treats its ACK state as content integrity. Crucially, every engine also predicts **separate intact historical 128-bit printer packets** that were withheld from its state/parameter fit.

These whole-packet forecasts are **not** interchangeable with tautological fits to the first observed coupon, or with tests that inspect only one 32-bit native word. True full-object synthetic producers were planted independently in each framework and correctly reconstructed their complete withheld packets. The 16-byte original K04 acceptance check was applied to each emitted complete candidate, even if its source holdout had already failed. For the two models that cannot uniquely emit a complete candidate, no arbitrary unknown bits were supplied.

The five model classes overlap (for example, the arbitrary 32-bit affine publisher subsumes some named unwhitened xorshift32 machines). Thus the combined 3,871/51 figures are **counts of performed checks, not 3,642 independent random samples, and not a universal exclusion of all printer generators**. Each component report specifies its own chronology, source gates, exact math and limitations.

**Additional compact impossibility witness:** The stateless metadata model has a four-row target-independent contradiction on actual original ordinary jobs 0300/0303/0305/0306: the entire augmented input metadata XOR is zero under both numeric and ASCII encodings, but the observed whole 128-bit packet XOR has 55 set bits. This refutes all matrices in the corresponding unrestricted GF(2)-affine producer family without any generator seed, original K04 digest or copied ACK2 input. Two complementary 32-bit native source-order certificates on the selected RECOVER class have 16- and 10-transition zero-input-XOR / nonzero-output-XOR contradictions. See the [explicit source-only certificate](h17-k04-affine32-selected-class-two-source-contradiction-certificates-20261128.md).

## Strongest supported conclusion

None of these source-frozen native and metadata-dependent issuer models explains even one *untouched and independently preserved* complete packet at the predicted source position, nor the original K04 commitment. The source-to-selected-coupon linkage is **not validated** for any of them. Fitting more free parameters to the copied 18:02 ACK would be especially misleading: the source itself says ACK authenticates dispatch, not physical payload integrity.

The same record also offers **no independent physical coupon, native .SPL/.SHD print queue stage or authenticated original whole-buffer checksum** for `PS-261003-0417` attempt-2. Hence the source data do not select another complete physical candidate. A failure here is a bounded producer falsification, **not** evidence that K04 is definitely generated by an entirely random process or that a SHA256 preimage has been recovered.

## Operational next decision for researchers

Further efforts should prioritize finding one of these **specific original-issuer bridges**, rather than naming new PRNG families:

- An authentic physical attempt-2 coupon, native spool object or its independently preserved complete-object checksum, with the source stage/time/job selection proved by original metadata.
- A genuinely source-selected generator specification/state copy that **predicts at least one unfitted intact 16-byte printer packet before testing K04**.
- Separately for K08, the exact author-final envelope/margin wording or a source-determined complete edit; nonverbatim N20 motif paraphrases remain insufficient.

If such a witness is obtained, the correct target-facing reducer already exists and the original acceptance gate is unchanged. Until then **K01,K02,K03,K05,K06,K07 PASS; K04 and K08 MISSING; combined archive INCOMPLETE.** Do not write guessed preimages into canonical `candidate.json` or weaken acceptance.
