## New mechanism and distinction from prior work

Agent11's earlier [two-future-donor method](h17-k04-two-donor-inverse-twist-source-carrier-test.md) hypothesized source carriers at **native stages 1347..1350 and 1574..1577**, inverted their difference and generated 127/128 bits of the selected 951..954 coupon. This experiment instead uses two *earlier* fourword blocks: **328..331** and **724..727**, invoking the **forward** source recurrence, and deriving all 128 target bits from them plus one high-bit choice. They are different stage assignments and a different information flow, despite sharing the 533-value source-carrier collection.

Use untempered native MT words `X[t]` and `tw(a,b) = (((a & 0x80000000) | (b & 0x7fffffff)) >> 1) xor (0x9908b0df if (b&1) else 0)`. Then

```
X951 = X724 xor tw(X327, X328)
X952 = X725 xor tw(X328, X329)
X953 = X726 xor tw(X329, X330)
X954 = X727 xor tw(X330, X331)
```

Only the high bit of the omitted `X327` enters this reconstruction, giving **two fully specified 16-byte selected coupon candidates per donor-pair/encoding assignment**. Temper the four words, serialize little-endian, XOR the original unchanged 16byte mask `8556C8CB6140A7F9A5123AC7571BEE1C`, and compare full SHA-256 with original K04 commitment `930a52a1bab97ca2966332137c99e99298ea6182fb32ab63a3421dfb4fd8c9e0`.

The donor pair hypothesis is **not historically attested**. The original source neither assigns the retained 16-byte objects to these past-gap stages nor authenticates the selected printer ACK. The model is a targeted alternate complete-candidate generation mechanism.
