## Interpretation for next researchers

These are **specific model exclusions**, not a prior on every generator family or proof of irrecoverability. Source records do not attest the speculative common state, common fixed role postprocessor, 1–4-donor parity code, or seeded CRC/FNV metadata emitter. The tests are useful precisely because they ask whether an intact original selected output can be predicted *before* taking the model to 0417's unverifiable copied coupon. The physical printer audit contains 128 ordinary `+00:00` rows and five later `Z` rows, so cross-cohort processing may change. No same-purpose, physically validated 0417 attempt2 coupon is available in the surviving export. The 0420 attempted printer control switches CLASS from STORES to RECOVER, so it cannot be treated silently as a same-class heldout retry.

The original repository resources spool, crew notes and acceptance files each entered with the initial commit on 20 October 2026, and only `main` was visible in repository branch listing. An earlier GitHub source revision of these files cannot serve as an observed pre-corruption original. The K08 exact authored caption remains unquoted in the local export, so none of these K04 experiments bears on its missing HMAC message.

**Next mechanism should change the source equation:** find an independent authentically preserved full selected coupon/complete phrase, or a producer model that *predicts complete intact historical selected records* under frozen inputs with no per-output free 128bit pad. Do not expand the failed transforms with arbitrary individualized salts or burn CI on equivalent copy-fault families without a new source cue. Do not edit original evidence, acceptance or verifier.
