Test whether those perfect disclosures, along with the entire intact historical printer source, determine the missing target's 128-bit native output.

## Exact test

Use the original SHA256-pinned spool, omit row129's copied PAYLOAD *before decoding*, reconstruct Agent10's frozen all-42 four-fresh stage vector (ten fixed gap deltas), and solve all 16,896 intact printer bits using the original MT19937 recurrence. The source system has rank **15,434**. The selected fourword target has quotient rank **128** before the hypothetical oracle.

For each of four fixed bitplanes, add the native or tempered high/low two bit expression for **all 440 otherwise unobserved interpacket words** to the source's GF(2) row space. Calculate the remaining target quotient rank without using the target copied bytes, the K04 mask, or any acceptance commitment. This is an idealized, information-maximizing source-observability test, **not** a claim that printer categories were generated from these bitplanes.

## Decision and reproducibility

A new CLASS/DEST-codebook search that merely varies how two native/tempered bits are mapped to three categories **cannot determine the full selected coupon under this fixed four-fresh chronology**, even if every hidden draw's two bits were directly observed. Such tests might constrain a few bits, but **at least 116 unknown bits remain** under the strongest four-bit native endpoint oracle reported here. This does **not** exclude a different native stage chronology, a high-density cross-source donor, a whole-buffer copy/emitter relation, or a separate printer generator. It makes a new 2-bit category sampler an inefficient complete-K04 recovery path on the already source-consistent all-fresh schedule.
