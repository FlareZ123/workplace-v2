## Next research: break the coupling assumptions, then spend compute

**K04 selected-object path.** Reconstruct the **lifecycle** of one actual object: producer bytes → selected job/attempt → dispatch buffer → mask → physical/copy-stage artifact → slot reducer. Freeze at least two materially different stage placements or selector interpretations *before* using the commitment. Establish exactly which retained whole historical job each would predict, withhold its complete packet and selector, and test the predictions. PS-0416 may be a same-role ACK/RECOVER control only where the proposed mechanism genuinely predicts it; an archived ACK is not a physical-copy ground truth. If the available data cannot discriminate models, develop a different source relation or encoder, rather than converting missing evidence into an endless wait. Relevant starting points: [ACK/copy integrity](h17-ack-selector-integrity-audit.md), [original route provenance](h17-k04-k08-shared-route-parameter-provenance-20261108.md), and [HST-4 index hypotheses](h17-hst4-pv-spool-job-crosswalk-20261107.md).

**K08 author-final path.** Separate *which document/version is final* from *how its text is generated*. Start with a source-dated document graph of exact quotations and retained final labels, freeze author and role restrictions, then withhold complete real label/caption text when testing the claimed revision operator. The withheld object must be eligible for the same claimed editorial operation; arbitrary HMAC-checkable new sentences do not validate it. If no eligible retained final exemplars exist, identify the specific missing document-selection relation and try a different source-production mechanism. Distinguish document-side history from speculative note→spool transport. Start with [role/source join graph](h17-source-role-join-graph-20261107.md), [physical margin carrier](h17-k08-physical-carrier-and-book-locator-synthesis-20261107.md), and [the source-first reversal](h17-k08-source-first-note-spool-join-null-holdout-20261109.md).

**Independent recovery architecture.** The route JSON is a transcription, and the [K04/K08 shared-route audit](h17-k04-k08-shared-route-parameter-provenance-20261108.md) establishes a common export container, not a common error or common key. A distinct stage/reducer dependency is worth a bounded model-driven test if it makes new predictions for several known complete reductions, ideally held out. Do not infer a universal polynomial relation from a failed guessed RS code.
