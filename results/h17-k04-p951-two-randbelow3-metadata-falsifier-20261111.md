# K04: p951 printer metadata cannot be two standalone CPython 3-way choices

**Agent 1 | 11 November 2026 | Source-only original holdout, no selected coupon or acceptance digest read.**

The 133 original printer packet rows, of which row129 is the disputed selected ESC-N ACK2, have a conditional MT19937 p951 chronology constructed in [Agent 4's exact source projector](../agents/agent4/k04_mt_full_state_gf2.py). This experiment asks whether its **127 gaps between the 128 ordinary five-minute packets** can be explained solely by two ordinary Python `random.choice` calls over three options (one for CLASS, one for DEST). This would be a concrete alternative printer-capture scheduling rule with a detectable high-two-bit signature, rather than an unconstrained metadata correlation.

For `randbelow(3)`, a two-bit sample of 3 is rejected and a final sample of 0,1,2 determines the choice. For each observed gap length, allow **every possible split** into two positive-length rejection-sampling runs. Test both CLASS→DEST and DEST→CLASS, both metadata alignments to the current or following job, and all 3!×3! fixed global bijections of the three original CLASS and DEST labels to 0,1,2: **144 complete source models**. Each proposed two-bit event is compared to the real-source-pinned MT symbolic basis, giving every model the benefit of unknown free source bits. A gap counts as compatible if any split satisfies all already source-fixed high-bit constraints.

The unmodified printer-source basis has rank **15,365**, withholding the selected row129. The 127 ordinary packet gaps contain **434 hypothetical extra native MT words**. Among their 868 high-bit observations, **294 are fully source fixed**, with many of the others genuinely unknown. Thus this is deliberately a *necessary compatibility test*, not the stronger requirement that a joint assignment over all rows exists.

The first **96** ordinary gaps were used to select a global producer codebook; the last **31** CLASS/DEST pairs were withheld from codebook selection. Best fit is **62/96 training** plus **18/31 holdout**, or **80/127** original whole-metadata gap events. No tested codebook reaches a full historical fit, even when every individual gap is free to choose its own rejection split. A necessary source condition already fails in **47** complete events for the best model.

**Implication:** Reject the exact hypothesis that the published p951 chronology's hidden draws are *only* two 3-way CPython metadata selections in either role order. This does not reject the true printer producer, other chronology alignments, additional draws, independent metadata channels or other selection laws. In particular, it does not determine a single authentic bit of the selected coupon. Do not infer the actual `CLASS`/`DEST` producer from this conditional negative.
