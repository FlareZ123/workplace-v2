## Why this is a substantive, separate original-output test

The prior historical **later-request** xoroshiro128++ inverse lanes are big-endian/AB (Agents 6/13) and little-endian/BA (Agent 8). Forward-request big-endian/BA is handled by Agents 7/41. This experiment fits only intact **PS-261003-0417 REQUESTED3** under the otherwise unclaimed **little-endian, packet word order AB** interpretation, and reverse-generates complete historical-coupon candidates. The copied selected ACK2 payload is neither a fitting observation nor a search anchor. REQUESTED1 is only an independent diagnostic, never an acceptance veto.

For each 12-bit parent, an exact first-two-output Boolean circuit searches all sixteen P16 child assignments for four additional initial-state-word bits. Every satisfiable full initial state is blocked and searched again. A state found before terminal timeout would be reduced against the unchanged full K04 commitment **before** any earlier-request replay filter. Every first-stage UNKNOWN is an open subdomain, never a zero.

The first historical run covered **all 2,048** P16 children in parent range **0..127** using a 350→700 ms two-stage exact per-child policy. It returned **2,022 terminal UNSAT and 26 UNKNOWN**, no full state models. The 26 UNKNOWN children were then each divided into **all sixteen** exact P20 grandchildren (additional unknown state bits 8..11, not externally supplied guessed state) with the same bounded policy and complete within-subcube blocking. All **416 P20 grandchildren** returned terminal UNSAT. Because each P16 region equals the disjoint union of those sixteen grandchildren, these exact outcomes convert the entire 26-child unresolved set to a definitive exclusion.
